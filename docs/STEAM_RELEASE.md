# Source snapshot and beta use

WoG Storage Helper automates tier-only inventory storage for Steam app 4891320.
Launch the game, open Helper, choose T3–T6 and an interval, then press Start.
Intervals range from 1 minute to 24 hours; the default remains 30 minutes.
The first sorting cycle is immediate; subsequent cycles use the chosen timer.
The app automatically locates the game and panels. Item levels and a separate
gem switch are not part of the product flow; no manual recognition calibration
is required in the settings.

Only confirmed existing storage pages are clicked. The recognised page count
is 2–6; the upgrade/purchase control is excluded. Two complete confirmed-full
sweeps stop the worker and countdown. Free storage space and explicitly press
“Space cleared” to recheck and restart. F8 or Stop cancels ongoing work.

Normal operation is local. Program screenshots, matching and ordinary Windows
mouse input stay on the computer. No game-memory reads, injected code, network
interception or achievement writes are performed.

This source snapshot is a reviewable beta. The included synthetic tests are
reproducible separately from the private development corpus. Long unattended
runs, every physical monitor/DPI arrangement and a clean Windows installation
remain separate validation tasks. Unknown recognition and an unproved inventory
boundary do not become a false success. Pending checks may keep the normal
timer after independently verified visible transfers; unverified input stops
without repeated item clicks.

This Beta.8 preparation retains recovery for passive drops and changed recognition
before item input. It captures a fresh stable baseline and chooses the item
again. An unconfirmed panel position may be retried automatically when no issued
input is awaiting verification. Healthy incomplete checks keep the configured
timer and display pending, including cycles with no transfers. The event text
does not claim that the player resized the game. The session log is append-only
and remains available when a dependency configured logging first.

The Beta.8 preparation adds tiny authenticated T4 glow resources while keeping
the independent grid proof and tier thresholds. Safe recognition failures get
two quick retries; continued uncertainty waits for the normal selected interval
instead of keeping the game in a rapid retry loop. Unknown or unverified item
input still stops further automation.

These source paths have dedicated synthetic regression tests. Their public
results belong to this exact export; native unattended validation remains a
separate task. This local snapshot preserves existing Beta.6 and Beta.7 artifacts
and does not claim a published or signed Beta.8 release.
