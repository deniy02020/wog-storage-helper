# Bundled recognition resources

These resources initialise an automatic matching profile. Users choose tiers
and a timer; the normal settings contain no manual calibration controls.

The exported source keeps the exact small PNG matching fragments and approved
dimensions, model thresholds and hashes. Original private source filenames
are replaced by `private-source-withheld.png` in metadata. The sentinel is not
a runtime file reference or an asset users must supply. Source hashes and
rectangles describe withheld original evidence; they do not distribute it.

Only T3–T6 may be transferred. T1/T2 samples support occupancy/negative checks
and never enable low-tier transfers. Gems and equipment share the tier filter.
Full game frames, user profiles, captures and internal development history are
excluded from this source snapshot.

Game-derived fragments retain their respective rights. Helper's own code and
original product assets use MIT; third-party notices are preserved separately.
